# Gamer Base - Download

Instalador do app desktop do Gamer Base (Windows).

**Baixar a versão mais recente:** [Releases](../../releases/latest)

Baixe o arquivo `Gamer-Base-Setup-<versão>.exe` e execute.

## Aviso do Windows

O instalador ainda não é assinado digitalmente, então o Windows pode mostrar
"O Windows protegeu seu PC". Clique em **Mais informações** e depois em
**Executar assim mesmo**.

## Atualizações

O app não atualiza sozinho. Para atualizar, baixe o instalador mais novo e
instale por cima.
